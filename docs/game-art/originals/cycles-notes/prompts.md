# Motion cycle prompts

Each render used the built-in image tool with transparent background enabled. For each cycle, every attempt used the exact prompt below. The rabbit-hop pilot and the animal's vocabulary PNG were the style references. The attempt log records which references were attached. The pilot was used as a visual comparison for the vocabulary-only attempts.

## rabbit-run

Vocabulary reference `assets/topics/mammals/vocabulary/rabbit.png`

- Render 1. Both style references, pilot first. The push-off followed the hop pilot's shape. Whiskers crossed the vertical cut.
- Render 2. Both style references, vocabulary image first. The bunch and push-off still resembled the hop pilot.
- Render 3. Vocabulary reference attached. The gallop extension was clearer, but a paw and edge detail crossed the vertical cut.
- Render 4 (delivered). Vocabulary reference attached. Selected for clean cuts and a clearer driving pose. The landing contact sits high and the bunched hind feet do not clearly overtake the front feet.
- Render 5. Vocabulary reference attached. The near-ground poses lined up more closely, but feet crossed the vertical cut.
